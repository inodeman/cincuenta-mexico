# Cincuenta — 50 shorts de México

Serie de 50 shorts verticales, uno por ciudad, para TikTok y YouTube Shorts.

Cada pieza trae:

- título
- descripción
- hashtags
- guion de voz en español
- imagen cinematográfica, audio y video vertical (cuando el paquete de medios está junto al short)

## Cómo publicar

1. Abre `posts/NN-ciudad.md`.
2. Copia el bloque **Pegar en TikTok**.
3. Sube el video `media/NN-ciudad.mp4` (imagen + narración) o, si editas aparte, la imagen y el mp3.

Canal: InodeAi.
